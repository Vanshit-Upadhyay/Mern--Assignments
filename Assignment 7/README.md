# Assignment 7 - CSS Grid Layouts - Chai Adda

## Main Objective
Learn two-dimensional layouts using CSS Grid.

## What I Made
Made three small pages in one folder using CSS Grid. All three pages are linked with each other using a navigation bar, so user can go from one page to another.

## Files
- gallery.html - A photo gallery with 9 images using display: grid and repeat(auto-fit, minmax(200px, 1fr)).
- product-grid.html - A product listing of 8 items using grid that reflows automatically when screen size changes.
- dashboard.html - A dashboard layout with header, sidebar, main and footer using named grid areas (grid-template-areas).
- README.md - This file

## Navigation
All pages have same navigation bar on top with links:
Gallery -> Products -> Dashboard
So all three pages are connected and user can move from one page to another.

## Grid Properties Used
- display: grid
- grid-template-columns
- grid-template-areas
- grid-area
- gap
- fr units
- repeat(auto-fit, minmax(200px, 1fr))

## Design Choices
Topic: Chai Adda, Budaun - Same topic as Assignment 5 and 6 to keep the project continuous.
Colours: Dark Green #12372A for main, Cream #FBF3E4 for background, Orange #FF7A00 for buttons and highlights.
Fonts: Sora for headings and DM Sans for body text.

## What I Learned
- How to make a photo gallery with grid
- How to make a grid that reflows automatically
- How to make a dashboard layout with named grid areas
- How to link multiple pages with navigation bar
- Difference between Flexbox (one-dimensional) and Grid (two-dimensional)
