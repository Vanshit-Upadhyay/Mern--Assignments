# Assignment 5 - Landing Page - Chai Adda, Budaun

## What I Made
A landing page for Chai Adda, a small tea shop in Budaun. It has Hero, Features, Gallery, Reviews and Contact sections.

## Sections in Website
- Hero - Name, introduction, Visit Us button and chai image
- Features - Kulhad Chai for Rs. 10, Fresh Pakoras and Free Seating
- Gallery - 3 photos of chai
- Reviews - 2 reviews from customers
- Contact - Address, timing and message form
- Footer - Copyright and name

## Design Choices
Topic: Chai Adda, Budaun - I selected my own idea to make the design original.
Layout: Used normal flow, inline-block and position. Flexbox and Grid are not used because sir told us not to use them yet.
Colours: Brown #4A2400 for main colour, Cream #FFF4E0 for background, Orange #FF7A00 for buttons and highlights. I did not use blue colour to make my design different.
Fonts: Sora for headings and DM Sans for body text. Sora looks bold and modern, DM Sans is easy to read.
Images: Used Unsplash images for hero and gallery.

## Files
- index.html - Structure of the website
- style.css - Design, colours and fonts
- README.md - This file

- How to make Hero, Features, Gallery, Reviews and Contact sections in HTML
- How to use Google Fonts and external CSS file
