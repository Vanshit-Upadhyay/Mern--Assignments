# Taj Trails - Explore Agra

A fully responsive landing page for Agra tours, built as part of Semester 1 MERN Assignment 9.

Reference: A travel / tour booking landing page, recreated from scratch with my own design and content.

## Live Demo
Open `index.html` with Live Server in VS Code.

## What I Built
Taj Trails is a simple landing page for Agra tours - Taj Mahal Sunrise Tour, Agra Fort + Old City Walk, and Fatehpur Sikri Day Trip. Users can see tours, prices, photos and book a tour.

## Features
- Fully responsive landing page
- Sticky navbar with hamburger menu on mobile
- Hero section with text + image
- Tours / Services section with 3 cards
- Photo gallery
- About + Footer section
- Semantic HTML, CSS variables, meta tags, meaningful alt text

## Tech Used
- HTML5 - Semantic tags: header, main, section, article, footer
- CSS3 - Flexbox, Grid, Variables, Media Queries
- No JavaScript / No Framework - Pure HTML + CSS
