# Assignment 4 - Portfolio Website - Vanshit Upadhyay

## What I Made
A simple portfolio website for myself. It shows my introduction, skills, education, college details, projects and contact form.

## Sections in Website
- Home - Name and introduction
- About Me - About my learning and goal
- My Skills - HTML, CSS and Problem Solving
- Education - B.Tech CSE at Invertis University, Bareilly
- My College / My Course - Subjects, learning steps and course details
- My Projects - Portfolio Website and HTML Form
- Contact Me - Email, GitHub and message form

## Design Choices
Fonts: Sora for headings and DM Sans for body text. Sora looks bold and modern, DM Sans is easy to read.
Colours: Dark Green #12372A for main colour, Cream #FBF3E4 for background, Orange #FF7A00 for highlights and buttons, White #FFFFFF for cards. I did not use blue colour to make my design different.
Layout: Used normal flow and simple positioning. Flexbox and Grid are not used.
Profile Photo: Arch shape, 180px x 220px, with 4px orange border. I did not use normal round photo.

## CSS Used in style.css
- CSS Variables: Used :root for colours, fonts, sizes, spacing and padding. Example --main-color, --cream-bg, --orange, --heading-font, --body-font.
- Element Selector: body, h1, h2, h3, img, nav, input, textarea, button, footer
- ID Selector: #top, #about, #college. #about has white background and orange left border.
- Class Selector: .profile-img for arch shape photo.
- Descendant Selector: nav a and section article ul li
- Child Selector: section > h2
- Pseudo-class: nav a:hover and button:hover for hover effect
- Heading size is 28px and body size is 16px.
